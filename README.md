# Sistema de Agendamento para Microempreendedores 
**Projeto Integrador I - UNIVESP (Grupo 2)**

## 📌 Sobre o Projeto
O projeto visa facilitar a gestão de horários para profissionais autônomos, permitindo o autoagendamento por parte dos clientes e o controle de fluxo para o prestador.

## 🛠 Tecnologias Utilizadas
- **Frontend:** React + TypeScript (Vite)
- **Backend:** Node.js + NestJS (Framework Progressivo)
- **Banco de Dados:** PostgreSQL 
- **ORM:** TypeORM ou Prisma (para abstração do banco)
- **Versionamento:** Git & GitHub (Fluxo de Pull Requests)
